Re-order — when the request fails

Three failures, three plain messages. No status code or error name ever reaches the page (U-B4). The server’s own message is used when it sends one.

← Portal home
A · Order not found
We couldn’t find that order.
It may have been removed, or it isn’t on your account. Nothing was added to your basket.
Go to your orders

Same message whether the order doesn’t exist or belongs to someone else (server 404).

B · Order can’t be re-ordered yet
This order can’t be re-ordered yet.
It’s still awaiting payment. Once it’s paid you can re-order it. Nothing was added to your basket.
View the order

Normally prevented by the disabled button; shown if the order changed in another tab (server 400).

C · Basket changed meanwhile
Your basket changed while we were adding these items.
Nothing was added this time. Try again and we’ll add what’s available.

Usually another tab or device editing the basket at the same moment (server 409).

The message replaces the lists inside the result dialog; closing it returns focus to the Re-order button that opened it (U-B6). Status codes appear only in these design captions, never in the product.

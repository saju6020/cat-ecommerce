Cat clinic SRS · clickable design review

PurrCare

18 areas, 427 screens. Every staff screen shares one collapsible sidebar and header; customer screens keep the customer portal’s own header and add the warmer “Hearth” customer layer (cream pages, pill buttons, warm-soft bands, apricot highlights, round cat avatars, a line-art cat in empty states). Pick an area to browse its screens.

The .dc.html files are the committed design source. support.js in each folder (copied from _shared/) renders them locally, makes them fluid, and rebuilds every staff screen into the shared shell. Serve this folder with any static server, e.g. python -m http.server 8080, and open http://127.0.0.1:8080/.

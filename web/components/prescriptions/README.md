# Pharmacy components exported for other slices (HO-PHM-002 §8.6)

These have no route dependency. They fetch through `lib/hooks/*`, render the SERVER's answers and never
navigate on their own — the caller decides what happens next.

| Component                                     | Where                                                      | Props                                                                                                                                                | Notes                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `PrescriptionComposer`                        | `components/prescriptions/PrescriptionComposer.tsx`        | `catId`, `visitId?: string \| null`, `renewFrom?: string` (the id of the prescription being renewed), `onIssued(prescriptionId, prescriptionNumber)` | Place it inside your own layout, beside the draft note. Without `visitId` and without `renewFrom` it renders the _open a visit first_ message and no form. With `renewFrom` and no `visitId` it is a remote renewal (owner decision 2026-10-10). Only a vet sees the form; anyone else gets `PermissionDeniedState`. Keep dialogs OUT of the `<form>` it renders (React portals bubble submit events). |
| `DietAuthorisationForm`                       | `components/diet-authorisations/DietAuthorisationForm.tsx` | `catId`, `visitId: string \| null`, `onAuthorised(authorisationId)`                                                                                  | Same visit rules.                                                                                                                                                                                                                                                                                                                                                                                      |
| `VisitPrescriptionsList`                      | `components/prescriptions/VisitPrescriptionsList.tsx`      | `visitId`, `catId?`                                                                                                                                  | Read-only list for a discharge-summary preview; `catId` turns each number into a link.                                                                                                                                                                                                                                                                                                                 |
| `WitnessDialog`                               | `components/pharmacy/WitnessDialog.tsx`                    | `open`, `onSubmit({ identifier, password })`, `onCancel`, `witnessRoles`, `busy`, `error?`, `confirmLabel?`, `title?`                                | A modal. The credentials live in its local state only and are cleared on submit, cancel, close, unmount and every refusal. **Never put what `onSubmit` receives in a TanStack mutation, a query key, the URL or storage** — call the API from a plain function (see `useDispense`).                                                                                                                    |
| `Quantity`, `SignedQuantity`, `QuantityInput` | `components/common/Quantity.tsx`                           | `value: { amount, unit }`                                                                                                                            | The only way to show a dose, quantity, weight, strength or range. Units come from `lib/format/units.ts`.                                                                                                                                                                                                                                                                                               |

Rules that hold across the slice: the client never computes a dose, matches an allergy, orders batches or
compares an expiry (`tests/components/common/clinical-logic-scan.test.ts` fails the build if it does);
buttons come only from the API's `allowedActions` / `canRequest`; register entries, dispensings and issued
prescriptions have no edit control.
